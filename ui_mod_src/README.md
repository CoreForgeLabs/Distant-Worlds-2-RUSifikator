# UI-мод русификатора Distant Worlds 2 - исходный код (v2.0.0)

`RussianUiMod.dll` (C#, net8.0, Harmony) - библиотека, которая работает вместе с текстовой частью русификатора:
- подгоняет окна под русский текст (карточка исследования и другие);
- собирает по-русски то, что игра склеивает в коде из английских кусков: названия держав, кораблей, руин, групп,
  теневых портов, предметов событий;
- показывает в главном меню панель автора и окно «Экипаж» (список поддержавших читается из `supporters.json`).

Игра грузит её штатным флагом `--low-level-inject "путь\RussianUiMod.dll!RussianUiMod.Entry.Init"` или через
DW2 Mod Launcher (`Entry.InitWithOptions`, настройки - `settings.schema.json`).

## Сборка

```
dotnet build -c Release -p:GameDir="D:\...\Distant Worlds 2" -p:RefDir="D:\...\ref"
```

- `GameDir` - папка игры: оттуда берутся `0Harmony.dll` и `Stride*.dll`.
- `RefDir` - папка со справочными сборками `DistantWorlds.Types.dll` и `DistantWorlds.UI.dll`. Это код самой игры,
  поэтому в репозитории его нет: сборки игры на диске защищены, справочные копии с открытыми членами снимаются с
  работающей игры (см. комментарий в `AccessChecks.cs`).

Исходники этого коммита собираются в ту же DLL, что лежит в архиве версии 2.0.0.

Актуальная версия русификатора целиком (тексты, шрифт, установщик) - на Boosty: https://boosty.to/coreforgelabs
